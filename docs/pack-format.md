# The `.srpack` avatar pack format

An **avatar pack** (`.srpack`) is one portable file holding one animated Shadowrunner character:
its layered rig, every image the rig draws, the saved look (palette, hidden layers, emotion,
colours, shapes), the voice and a manifest that says who made it and how it may be used. The
Shadowrunner creator exports and imports packs; any other app can read one with `@sr/pack`
(`packages/pack`, React-free, depends only on `@sr/rig` and `fflate`).

The recorded cast is published as sample packs at `/packs/<slug>.srpack`, listed in
`/packs/index.json` (`[{ "id", "name", "file", "bytes" }]`, sorted by id). They are generated by
`scripts/build-packs.mjs` on every `pnpm dev` and `pnpm build`. Malakor is never packed.

Format version: **1**. Source of truth: `packages/pack/src/types.ts` and
`.kiro/specs/avatar-pack/design.md`.

## Container
A pack is a standard zip archive whose entries are **stored** (no compression: the images are
already compressed). Entries, in this order:

| path | content |
|---|---|
| `pack.json` | the manifest (below), UTF-8 JSON, 2-space indent, trailing newline |
| `rig.json` | the rig, Rig format v1 (`@sr/rig` `serializeRig`) |
| `README.txt` | plain text for people: name, what a pack is, licence, author, fictional note, a link to this document |
| `files/<name>` | one entry per image, sorted by name; `<name>` is the file key the rig uses |

- An image's `<name>` is a relative POSIX path exactly as the rig names it: a layer's `file`, a
  layer's `regions.map`, or an expression patch's `variants.<family>.file`. Formats are PNG and
  WebP (JPEG is tolerated by readers); the MIME type comes from the extension.
- The rig never holds inline `data:` images inside a pack. A writer moves them to `files/`: a
  layer image to `<layer>.<png|webp>`, a region map to `<layer>.regions.<ext>`, a patch to
  `<layer>.<family>.<ext>` (with `-2`, `-3`, ... when a name is taken) and rewrites the rig.
- Every entry's timestamp is the zone-less DOS time 2026-01-01 00:00:00, so a pack's bytes depend
  only on its content. Two exports of the same character, look and manifest are byte-identical.
- Readers look only at `pack.json`, `rig.json` and `files/*`; other entries (including
  `README.txt`) are ignored, and so are images the rig does not reference.

## Manifest (`pack.json`)
Optional fields are **omitted, never `null`**.

| field | type | meaning |
|---|---|---|
| `format` | `"srpack"` | format id |
| `version` | `1` | format version |
| `app` | `"shadowrunner"` | the writing app |
| `exportedAt` | string | ISO 8601 time of export |
| `id` | string | the character id; equals `rig.id` |
| `name` | string | the character name; equals `rig.name` |
| `look` | object | the saved look (below) |
| `voice` | string | a Shadowrunner voice id (`crypt`, `clerk`, `choir`, ...) when written by Shadowrunner; readers must tolerate others |
| `licence` | string | one of the licence values below |
| `author` | string, optional | who made it; omitted when empty |
| `source` | `"forge"` \| `"replay"` \| `"import"` | how the rig was made (`rig.source`) |
| `fictional` | `true`, optional | present exactly when `rig.fictional` is true: the character depicts no real person |
| `createdAt` | string, optional | ISO 8601 creation time of the character, when known |
| `sheet` | object, optional | who the character is on air (below); omitted when it has none |
| `files` | string[] | every image name under `files/`, sorted |

### Look
| field | type | meaning |
|---|---|---|
| `palette` | object | the rig palette to draw with (same shape as `rig.palette`) |
| `hidden` | string[] | layer names drawn invisible |
| `emotion` | string | the resting emotion (`neutral`, `amused`, `smug`, ...: `@sr/rig` `EMOTION_TABLE`) |
| `gesture` | string, optional | `nod`, `tilt`, `lean_in`, `recoil`, `glare` or `flare` |
| `regions` | object, optional | region colours keyed `<layer>/<slotId>` -> `#rrggbb` |
| `shape` | object, optional | part reshapes keyed by layer name |

The look is read against the pack's own rig (`@sr/rig` `readLook(look, rig)`). A missing or
malformed base field (palette colours as `#rrggbb` for `glow`, `eye`, `rim`, `mouth`; `hidden`;
a known `emotion`; a known `gesture` when present) makes the pack invalid (`bad_look`). A single
`regions` or `shape` entry that does not fit the rig is dropped, not fatal.

### Sheet
| field | type | meaning |
|---|---|---|
| `archetype` | string | what kind of character it is, 1-120 characters |
| `hook` | string | its persona hook, 1-400 characters |
| `lines` | string[] | 0-3 example lines it would say on air, each 1-160 characters |

The sheet is the brief the streamer approved for a forged character (`@sr/pack` `readSheet`). The
stage builds the character's persona from it, and on the replay plane plays its lines as a short
scripted show. Text is trimmed. A sheet that breaks a rule is dropped, not fatal: the face still
loads. Readers that do not know `sheet` ignore it.

### Licence values
| value | meaning |
|---|---|
| `all-rights-reserved` | All rights reserved: ask the author before sharing or reusing (the published cast packs use this) |
| `CC-BY-4.0` | Creative Commons Attribution 4.0 |
| `CC-BY-NC-4.0` | Creative Commons Attribution-NonCommercial 4.0 |
| `CC0-1.0` | CC0 1.0, no rights reserved |

## Validation and errors
`readPack(bytes | ArrayBuffer | Blob)` and `loadPack(url | Blob)` return
`{ ok: true, pack }` (`pack` = `{ manifest, rig, look, voice, files }`, `files` = image Blobs keyed
by name) or `{ ok: false, error: { code, detail } }`. Checks run in this order; the first failure
is returned:

| code | when |
|---|---|
| `too_large` | the file, or what it unpacks to, is over 50 MiB (`PACK_MAX_BYTES`) |
| `not_a_pack` | not a zip, no `pack.json`, or `format` is not `"srpack"` |
| `newer_version` | `version` is greater than the reader's (`PACK_VERSION`) |
| `bad_manifest` | a manifest field has the wrong type or value, or `id` differs from `rig.id` |
| `bad_rig` | `rig.json` is missing or does not validate as Rig v1 (detail: first error path and message) |
| `bad_look` | the look does not read against the rig |
| `missing_file` | a layer image is missing from `files/` (detail: its name) |
| `fetch_failed` | `loadPack` only: a non-2xx answer or a network error |

Every layer image is required. Region maps and expression patches are optional: when absent the
character still draws (painted colours, no expression faces).

## Versioning
`version` is an integer. A reader refuses a pack whose version is higher than its own with
`newer_version`, and a pack whose version is not a known one with `bad_manifest`. The rig inside
carries its own `version` (Rig format v1), checked by `@sr/rig`.

## Use in a browser
Illustrative: this is what `@sr/avatar`'s React `<AvatarCanvas>` does each frame, minus audio,
gestures, resizing and WebGL-loss handling. In React, pass `rig`, `look` and `assets` to
`<AvatarCanvas>` instead.

```js
import { decodePackImages, loadPack } from "@sr/pack";
import { advanceFrame, createRenderer, initialState } from "@sr/avatar";
import { applyLook, poseLayers } from "@sr/rig";

const result = await loadPack("/packs/moth-widow.srpack");
if (!result.ok) throw new Error(`${result.error.code}: ${result.error.detail}`);
const { rig, look, files } = result.pack;
const canvas = document.querySelector("canvas");
const renderer = createRenderer(canvas, rig, await decodePackImages(files));
renderer.resize(canvas.clientWidth, canvas.clientHeight, devicePixelRatio);
const dressed = applyLook(rig, look);
const reducedMotion = matchMedia("(prefers-reduced-motion: reduce)").matches;
let state = initialState(1), last;
requestAnimationFrame(function frame(now) {
  const next = advanceFrame(state, { dt: last === undefined ? 0 : (now - last) / 1000, level: 0, gaze: "host", reducedMotion });
  state = next.state; last = now;
  renderer.draw(poseLayers(dressed, look, next.drive), look, { t: state.t, reducedMotion });
  requestAnimationFrame(frame);
});
```

`level` is the audio level, 0..1, that opens the jaw (take it from audio with `@sr/avatar` `attachAudio(node).level()`).
`@sr/*` are workspace packages of this repository, not published to npm.

## Embed
To show a pack on any web page without a build step, load the `<sr-avatar>` element from a
Shadowrunner deploy (`pnpm build` writes it to `apps/web/dist/embed/sr-avatar.js`, served at
`/embed/sr-avatar.js`; one ES module, no React). The `/embed` page shows it live on the cast and
copies this snippet for you:

```html
<script type="module" src="https://<deploy>/embed/sr-avatar.js"></script>
<sr-avatar src="https://<deploy>/packs/moth-widow.srpack" mood="smug" style="width: 320px; height: 320px"></sr-avatar>
```

| Attribute | Meaning |
| --- | --- |
| `src` | The pack's URL (relative URLs resolve against the page). Changing it loads the new pack. |
| `mood` | An emotion (`neutral`, `amused`, `smug`, ...); crossfades on change. Absent: the pack's saved look. |
| `background` | A CSS colour under the character. Default `transparent`. |
| `backdrop` | Boolean. Draw the rig's own painted backdrop (the layer named `background`). Absent: the character is a cutout over `background` and the page. |
| `mic` | Present: a "Click to listen" button lip-syncs the character to the microphone (the browser asks first). |

From script: `el.setMood(emotion)`, `el.gesture("nod")` (any rig gesture), `el.setLevel(0.6)`
(a mouth level 0..1 that wins over audio; `undefined` hands back), `el.attachAudio(audioElementOrNodeOrStream)`
(`undefined` detaches). Events: `sr-ready` once the character draws, `sr-error` with a sentence in
`event.detail` when the pack cannot be fetched or read (the element shows the same sentence).

The element sizes to its box (an inline block, 300 x 300 unless you style its width and height), shows a line while
loading, honours `prefers-reduced-motion`, and disposes its renderer, microphone and audio when
removed from the page. Packs and the script are fetched by the embedding page, so a cross-origin
embed needs the serving site to allow it (CORS); otherwise host your own copy of `sr-avatar.js`
and the `.srpack`.
